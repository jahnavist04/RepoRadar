# 🚀 RepoRadar

### Find your next favorite open-source project.

RepoRadar helps developers discover trending GitHub repositories, explore beginner-friendly issues, and find projects that match their interests.

[Explore Features](#-features) · [Quick Start](#-quick-start) · [Contributing](#-contributing)

---

## ✨ Features

- 🔥 **Trending Explorer** — Discover popular repositories by programming language.
- 🔎 **Smart Search** — Search projects by topic, name, or technology.
- 🌱 **Good First Issues** — Find beginner-friendly open-source contributions.
- 🤖 **Interest Matching** — Rank repositories by how closely they match your interests.
- 📊 **Repository Insights** — View stars, forks, issues, and programming languages.
- 🔗 **Direct Links** — Jump straight to repositories and contribution issues.

## 🛠️ Built With

- Python
- Streamlit
- GitHub REST API
- Optional OpenAI API for AI-powered recommendations

## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/RepoRadar.git
cd RepoRadar
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the app

```bash
streamlit run app.py
```

Open the local URL shown in your terminal.

## 🤖 Enable AI Recommendations (Optional)

Set an `OPENAI_API_KEY` environment variable to enable
AI-generated recommendations.

Without the key, RepoRadar still works using keyword-based
matching.

Never commit API keys or secrets to GitHub.
